### OpenAI and MCP

OpenAI's docs are blocked from this sandbox, so the ChatGPT points come from search results. Package and security facts were read from npm, its advisory database and the GitHub repos. Details: `00-platform-notes.md`.

**ChatGPT**

- **The Developer mode switch is gone** (early October). You add a plugin from **Settings → Plugins → + → Add custom MCP server**.
- **Your plan matters.** Custom plugins work on Business, Enterprise and Edu. Pro may be read-only, which is enough: every public Kept tool is read-only. Plus is unclear.
- **No share button on personal accounts.** Each tester adds the URL themselves.
- **UK:** very likely fine. Apps launched "outside the EU", and Rightmove and Zoopla have ChatGPT apps. One blog says otherwise. Your first test settles it.
- **Suggestions in chat** only go to directory plugins, and plain prompts rarely trigger them.
- **No analytics for plugin owners yet.** Our own log lines stay the only measure.
- **No change found** to submission rules, widgets, display modes or sign-in.

**MCP**

- **No new version of the standard.** The next is planned for 30 March 2027. Our widget uses the current one.
