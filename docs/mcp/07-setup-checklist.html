Part A. Make the plugin's home

On Vercel. About 10 minutes, mostly waiting.

1

Open Vercel

Go to vercel.com and log in.

2

Start a new project

Click Add New… then Project.

3

Pick your code

Find Bellwood-Lane-Ventures and click Import.

This is just your code's name on GitHub. Customers never see it.

4

Name it

In Project Name, type:

kept-plugin

This name becomes the web address, so it must say kept.

5

Choose the folder

Next to Root Directory, click Edit. Pick this folder, then click Continue:

apps/plugin

This is the most important step. If it's wrong, nothing works.

6

Add the energy key

Open Environment Variables. In the first box (the name), paste:

EPC_API_TOKEN

In the second box (the value), paste the key from your bellwood-api project. It's in Settings → Environment Variables. Open it in a new tab.

Click Add.

Why: energy certificates come from a government register that needs this free key.

Can't find it? Get a free one at get-energy-performance-data.communities.gov.uk. Sign in with GOV.UK One Login, open My account and copy the token.

7

Deploy

Click Deploy. Wait 3 to 5 minutes, until you see the celebration screen.

8

Let ChatGPT in

Go to Settings → Deployment Protection. Under Vercel Authentication, choose Standard Protection. Click Save.

If this stays on the stricter setting, ChatGPT gets blocked.

9

Copy your address

Go to Overview. Copy the domain. It looks like kept-plugin.vercel.app. Paste it here:

Your ChatGPT link is:

https://kept-plugin.vercel.app/mcp

Example shown until you paste your own address.

10

Tell Claude

Send Claude this message. Claude will check the plugin is working before you go on.

done

Part B. Connect ChatGPT

About 3 minutes. Use a computer, not your phone.

11

Open ChatGPT

Go to chatgpt.com and log in.

12

Turn on Developer mode

Go to Settings → Security and login → Developer mode. Turn it On.

Can't see it? Search Settings for "Developer mode".

13

Add a plugin

Go to Settings → Plugins. Click + (Create).

14

Fill in 3 boxes

Name:

Kept

URL:

https://kept-plugin.vercel.app/mcp

Auth: choose None. Then click Create.

15

Check it

You should see 4 tools.

Part C. Test it

About 5 minutes. Copy each message into ChatGPT and check the result.

16

Start a test chat

Click New chat. Click +, then Developer mode. Tick Kept.

17

Test 1: the inherited home plan

My mum died on 10 June 2026 and left me her house. It's empty. Probate was granted on 20 September 2026. What do we need to do?

You should see a card with dates. One line says 2026-12-31 · Inheritance Tax due.

18

Test 2: ways to sell

An agent says £250,000. We have a cash offer of £210,000. Legal fees are £1,200. What would we end up with?

You should see 3 columns: agent £245,050, auction £241,300, cash buyer £208,800.

19

Test 3: renovation costs

How much would it cost to renovate an 85 square metre house with damp?

You should see 3 cards: Light, Full and Heavy, each with a £ amount.

20

Test 4: public record

Type this, with your own address and postcode:

What's on public record about [your address], [your postcode]?

You should see "Public record · not a valuation" with the energy rating and floor area.

21

Test 5: no valuations

How much is my house worth?

It should not give a value or an offer. That is correct.

22

Test 6: the button, then tell Claude

On any card, click Ask Kept for a written offer. It should open wearekept.co.uk.

Then tell Claude how it went. Claude will read the plugin's logs to confirm each test.

If something goes wrong

ChatGPT says it can't connect Check the URL ends in /mcp. Check step 8. Then tell Claude.
Kept isn't used in the chat Check Kept is ticked under + → Developer mode. Or start your message with "Use Kept to".
Test 4 shows no energy rating The energy key from step 6 is missing or wrong. Add it, then go to Deployments → ⋯ → Redeploy.
Anything else Send Claude a screenshot. Claude can read the plugin's logs.
